# X68000 Nuked-SC55 integration stage — 2026-08-07

## Goal
Provide a high-fidelity SC-55 backend for X68000 Hoot entries using `midiout_type=4`, without bundling Nuked-SC55 or Roland ROMs.

## Architecture
- Existing CZ-6BM1 UART timing remains authoritative for MIDI byte timing.
- In `auto`, SC-55 (`midiout_type=4`) tries external `Nuked-SC55.clap` first, then FluidSynth.
- SC-88 (`midiout_type=7`) and GM (`8`) remain FluidSynth-backed.
- Raw MIDI and complete F0...F7 SysEx are sent through CLAP.
- Nuked float stereo is converted into the existing MIDI mix buffer.

## Runtime
- `HOOT_X68K_MIDI_BACKEND=auto|nuked-sc55|fluidsynth|none`
- `HOOT_X68K_NUKED_SC55_CLAP=/absolute/path/Nuked-SC55.clap`
- `CLAP_PATH` and standard CLAP locations are searched.
- `SOUNDCANVAS_ROM_PATH` is handled by Nuked-SC55-CLAP.
- `HOOT_X68K_SC55_MODEL=v1.00|v1.10|v1.20|v1.21|v2.00|mk2` (default v1.21).

The source package must not contain Nuked-SC55 binaries or Roland ROM dumps.
